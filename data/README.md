## messages.csv의 class 값

라벨 정의 문서가 없어서 **샘플을 직접 보고 추정**한 의미입니다. 원본 데이터셋 카드로 확인이 필요합니다.

| class | 건수 | 추정 의미 | 예시 |
| --- | --- | --- | --- |
| 1 | 5,778 | 정상 – 일반 글 (뉴스 댓글로 보임, 문자 아님) | "우리나라 못지않게 얘네도 유치하네 ㅋㅋ" |
| 2 | 10,531 | **스팸·스미싱** | 도박 광고, 택배·기관·가족 사칭 |
| 3 | 2,700 | 정상 – 택배 배송 안내 문자 (템플릿으로 생성된 것으로 보임) | "(우체국 배달완료) … 배송 완료하였습니다" |

참고 사항:
- class 2의 숫자와 일부 글자가 `*`로 마스킹되어 있습니다(`첫**%`, `sk***`). 실제 문자에는 `*`가 없으므로, `*`에 의존하는 규칙은 만들지 않았습니다.
- class 2의 대부분은 도박·성인 광고입니다. 택배·기관·가족 사칭은 수십~수백 건 수준이라 데이터가 적습니다.
- class 1은 문자가 아니라 댓글이라 "정상 문자"를 대표하지 못합니다. 정확도 평가 때 정상 문자 표본은 `ham.txt`와 직접 작성한 샘플로 보완해야 합니다.
- `index` 컬럼은 값이 중복되거나 비어 있어서 식별자로 쓸 수 없습니다.
